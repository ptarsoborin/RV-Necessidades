Importar relatório

Escolha o anexo recebido por e-mail ou arraste o arquivo para cá. Pode ser feito a qualquer hora do dia.
Obrigatória: define o que está atrasado. Se o nome do arquivo tiver a data (2026-10-22 ou 22-10-2026), ela é lida do nome e vale como data do relatório.

Relatório vigente

O relatório mostrado em todas as páginas é o escolhido no alto da tela, em “Relatório”. Cada importação fica guardada no servidor.

O que o sistema confere a cada importação

  • O sistema lê só a aba Geral, com as colunas do relatório; abas por comprador são ignoradas. Espaços nos cabeçalhos são ignorados.
  • Código do item único. Linhas de subtotal sem código são descartadas.
  • COMPRAR = PontoPedido − Disponível + VendProt − Comprado.
  • RUPTURA = menor valor entre 0 e (Disponível − VendProt).
  • Ruptura coberta quando Comprado é maior ou igual à falta: o item sai de Rupturas e vai para a cobrança de entrega.
  • Data de geração informada (campo ou nome do arquivo) e conferida com a última compra do relatório.
  • Arquivo idêntico a um já importado é barrado.

Importe um relatório para exportar.

Gera o relatório em PDF ou Excel com a foto da data-base. Os filtros das telas não alteram o que é exportado. Todo arquivo exportado fica desatualizado no dia seguinte.
